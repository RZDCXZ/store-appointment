# 16 — 店长预约列表与代客预约

**What to build:** 让店长搜索和查看门店预约，并把电话、聊天或到店达成的预约录入同一容量系统。

**Blocked by:** 02 — 后台演示账号与角色路由; 05 — 宠物档案与隐私同意; 07 — 顾客查询真实可约时段; 08 — 提交并确认预约.

**Status:** ready-for-agent

- [ ] MG-03 预约列表、MG-04 预约详情、MG-05 代客预约具备独立后台路由，可直接访问和刷新恢复。
- [ ] 列表支持按日期、状态、员工、主要服务和顾客／宠物关键字筛选，并能进入当前预约详情。
- [ ] 详情展示当前事实、顾客与宠物、本次服务、时间与员工、门店服务记录、变更历史和关联通知。
- [ ] 代客预约可选择已有顾客与宠物，或创建包含姓名、手机号和宠物最小字段的新档案。
- [ ] 代客预约记录当前隐私说明版本、线下确认来源和执行店长。
- [ ] 店长可绕过顾客端两小时提前量，但仍受营业、已发布排班、技能、冲突、停班、闭店和十四日窗口限制。
- [ ] 代客预约使用同一创建、幂等、快照、核销码、通知和数据库排除约束，不能建立免校验预约。
- [ ] 页面覆盖空列表、无搜索结果、字段错误、时段冲突、局部查询错误和无权限状态。
- [ ] API 与 Playwright 测试覆盖筛选、详情恢复、新旧顾客代录、线下同意和无法强制重叠。
- [ ] 路由映射记录 MG-03、MG-04、MG-05；抽屉可以作为视觉呈现，但必须由可寻址路由驱动。
