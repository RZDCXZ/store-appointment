# 18 — 预约内容纠正

**What to build:** 让店长在到店核销前修正错误的宠物体重、服务规格或增项，同时重新证明员工技能和连续容量仍然成立。

**Blocked by:** 16 — 店长预约列表与代客预约.

**Status:** ready-for-agent

- [ ] MG-07 预约内容纠正拥有独立可恢复的路由状态，从预约详情进入并显示当前快照。
- [ ] 纠正面板显示体重、体型、服务规格、增项、价格、服务时长和技能要求的前后对比。
- [ ] 体重变化自动重新计算体型与规格，不能由店长直接绕过体重规则选择体型。
- [ ] 保存前重新校验当前员工完整技能、营业、已发布排班、实际占用和宠物冲突。
- [ ] 纠正导致容量不足时拒绝保存，保留原快照并提供换员工、改期或取消的下一步。
- [ ] 成功纠正原子更新当前快照与实际占用，追加原值、操作人、原因和新值历史，并通知顾客。
- [ ] 更换宠物或完全不同的主要服务不允许通过纠正保存，界面引导取消后新建。
- [ ] 已到店或任何终态预约不能纠正服务内容。
- [ ] API 测试覆盖体型边界、技能不足、扩大时长冲突、缩短占用、原子失败和非法状态。
- [ ] 路由映射记录 MG-07，并验证刷新后前后对比不依赖临时组件状态。
