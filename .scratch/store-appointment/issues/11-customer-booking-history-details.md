# 11 — 顾客预约记录、详情、核销码与消息

**What to build:** 让顾客随时查看自己的未来和历史预约、当前有效核销码，以及由预约事实产生的模拟消息。

**Blocked by:** 08 — 提交并确认预约.

**Status:** ready-for-human

- [x] MP-13 预约记录、MP-14 预约详情与核销码、MP-16 消息分别使用真实小程序页面路径，可直接访问和刷新恢复。
- [x] 预约记录区分未来与历史，展示宠物、主要服务、计划时间、具体员工和预约状态。
- [x] 详情展示预约快照、状态与下一步、计划时间、价格、服务时长和具体员工；已完成时显示实际完成时间。
- [x] 有效预约显示六位核销码和“开始前 30 分钟至开始后 15 分钟”的窗口说明；取消或已核销后不再显示可用码。
- [x] 授权顾客刷新详情后仍能取得当前核销码，但数据库不得保存可直接复用的明文核销码。
- [x] 顾客只能读取自己的预约和消息；替换预约或消息标识不能越权访问。
- [x] 消息页明确标注模拟微信消息，并能从消息跳转到关联预约详情。
- [x] 已完成详情不展示门店服务记录、员工内部说明或其他宠物资料。
- [x] 页面覆盖无预约、无消息、加载、可重试错误、无权限和状态刚发生变化后的重新拉取。
- [x] 路由和权限测试覆盖 MP-13、MP-14、MP-16 的直接访问、刷新恢复与跨顾客越权。
