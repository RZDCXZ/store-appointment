# 26 — 顾客数据导出与匿名化删除

**What to build:** 让顾客查看并导出系统保存的本人资料，并在处理未来预约后匿名化个人和宠物数据而不破坏经营事实。

**Blocked by:** 12 — 顾客取消与顾客改期; 25 — 店长顾客与宠物档案及导出.

**Status:** ready-for-human

- [x] MP-18 数据导出与资料删除使用独立小程序页面路径，可直接访问和刷新恢复。
- [x] 顾客可导出只属于自己的结构化 JSON，包含顾客、宠物、隐私同意、预约和消息等可识别资料。
- [x] 每次顾客导出写入审计事实，但不在日志中输出导出正文、完整手机号或会话。
- [x] 存在未来预约时服务端阻止删除，页面列出需要先处理的预约并提供返回入口。
- [x] 删除使用两步确认，明确说明哪些个人资料会匿名化、哪些非身份经营事实会保留。
- [x] 删除后匿名化姓名、手机号、宠物档案、照片、护理资料和身份关联，不级联删除预约历史、统计或删除审计事实。
- [x] 匿名化完成后当前及其他旧顾客会话失效，不能继续读取删除前资料。
- [x] 历史预约与看板仍可使用不含身份的信息，界面不会重新拼接出已删除顾客身份。
- [x] 该页面明确说明这是演示保留规则，不表述为满足某个司法辖区的法律意见。
- [x] API 测试覆盖本人导出、越权、未来预约阻断、匿名化完整性、统计保留、会话失效和重复删除。
