# 05 — 宠物档案与隐私同意

**What to build:** 让顾客维护用于预约的宠物资料与护理信息，并在首次预约前留下版本化、可追踪的隐私同意。

**Blocked by:** 03 — 小程序演示顾客会话.

**Status:** ready-for-human

- [x] MP-03 宠物列表、MP-04 新建／编辑宠物、MP-05 隐私同意均使用独立页面路径，可直接访问和刷新恢复。
- [x] 顾客只能查看和修改自己的宠物；服务端拒绝通过替换宠物 ID 访问其他顾客档案。
- [x] 宠物必填名称、犬／猫和当前体重；体重输入即时显示正确体型，选填资料符合完整规格。
- [x] 顾客可设置护理标签和护理注意事项，界面明确它们不是医疗病历或诊断。
- [x] 照片上传校验类型和大小，保存到本地数据存储；失败保留表单内容并可重试。
- [x] 无未来预约的宠物可归档和恢复；存在未来预约时服务端阻止归档并指出关联预约。
- [x] 隐私同意记录版本、顾客和时间；首次未同意或版本更新后，预约入口必须要求重新确认。
- [x] 宠物列表区分在用与已归档，并覆盖无宠物、加载、字段错误、上传错误和无权限状态。
- [x] 小程序组件与 API 测试覆盖体型边界、归档阻断、版本化同意、越权和输入校验。
- [x] 路由映射记录 MP-03、MP-04、MP-05，并验证编辑页刷新后恢复对应宠物。
