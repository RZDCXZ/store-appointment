# 02 — 后台演示账号与角色路由

**What to build:** 让店长和员工使用各自预置账号登录同一后台，并确保角色导航、页面直达和接口访问都由服务端身份限制。

**Blocked by:** 01 — 三端可启动骨架.

**Status:** ready-for-agent

- [ ] ST-01 登录页按设计稿实现为独立路由，可直接访问和刷新恢复。
- [ ] 预置一个店长和四个员工账号，使用文档公开的统一演示密码，但数据库只保存安全哈希。
- [ ] 登录成功后使用 HttpOnly、SameSite Cookie 会话；写请求具备来源或 CSRF 防护。
- [ ] 店长登录后只看到工作台、预约、排班、服务、顾客、经营、系统导航；员工只看到今日工作和我的预约。
- [ ] 未登录访问受保护路由会回到登录页，并保留登录后可恢复的目标位置。
- [ ] 员工直接输入店长路由或调用店长接口时获得明确无权限结果，不能仅靠隐藏导航限制。
- [ ] 会话过期与密码错误使用不同、可恢复的提示，不把失败误报为服务器错误。
- [ ] 登录页在桌面和约 390px 宽度均可使用，支持键盘操作、可见焦点和关联错误信息。
- [ ] API 权限测试至少覆盖未登录、员工、其他员工和店长四类身份边界。
- [ ] 路由映射记录 ST-01 及角色落地页，验证直接访问和浏览器刷新。
