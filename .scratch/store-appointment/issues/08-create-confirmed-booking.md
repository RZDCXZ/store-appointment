# 08 — 提交并确认预约

**What to build:** 让顾客复核预约草稿并创建一笔立即确认、已分配具体员工且拥有核销凭证的预约。

**Blocked by:** 07 — 顾客查询真实可约时段.

**Status:** ready-for-human

- [x] MP-10 确认预约和 MP-11 预约成功使用独立页面路径，刷新后从服务端恢复当前预约事实。
- [x] 确认页完整展示宠物、主要服务、增项、具体员工、计划时间、价格、服务时长和周转说明。
- [x] 创建时重新校验隐私同意、服务状态、员工技能、已发布排班、宠物冲突和员工冲突。
- [x] 创建成功状态为已确认，并保存宠物体重、体型、服务、价格、时长、原计划区间与实际占用快照。
- [x] PostgreSQL 使用范围排除约束最终拒绝同一员工或同一宠物的有效重叠占用，不能只依赖应用层先查后写。

- [x] 真实 PostgreSQL 与 HTTP API 测试覆盖成功、重复幂等、员工冲突、宠物冲突、同一顾客不同宠物并行和非法状态。
