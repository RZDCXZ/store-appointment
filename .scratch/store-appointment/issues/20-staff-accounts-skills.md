# 20 — 员工账号与员工技能管理

**What to build:** 让店长维护员工账号与技能覆盖，并在停用员工可能破坏未来预约时阻止操作。

**Blocked by:** 02 — 后台演示账号与角色路由; 06 — 已发布排班形成可预约容量; 08 — 提交并确认预约; 19 — 主要服务、服务规格与增项管理.

**Status:** ready-for-human

- [x] MG-13 员工与技能使用独立后台路由，展示员工账号状态、班次摘要和清晰技能矩阵。
- [x] 店长可以创建员工账号、设置演示密码、停用账号并为主要服务及增项分配技能。
- [x] 新密码使用安全哈希保存，任何读取接口和日志都不返回密码或哈希。
- [x] 可约时段和“最快可约”立即使用最新有效技能，员工必须覆盖预约中的全部项目。
- [x] 有未来预约的员工不能直接停用，响应列出受影响预约并提供后续处理入口。
- [x] 停用成功后员工无法登录且不再产生新容量，历史预约仍显示员工快照与姓名。
- [x] 项目固定一个店长，不提供店长角色转让、多管理员邀请或员工互相改权。
- [x] 员工账号和技能变化写入追加式审计事实。
- [x] API 测试覆盖技能增删对时段的影响、停用阻断、会话失效、历史保留和越权。
- [x] 路由映射记录 MG-13，并验证技能矩阵键盘操作、错误提示和浏览器刷新。
