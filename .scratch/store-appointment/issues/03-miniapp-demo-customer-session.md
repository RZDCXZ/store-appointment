# 03 — 小程序演示顾客会话

**What to build:** 让本地体验者在三个有明确故事的演示顾客之间切换，并以服务端签发的顾客身份使用真实小程序导航。

**Blocked by:** 01 — 三端可启动骨架.

**Status:** ready-for-agent

- [x] 小程序提供首页、预约记录、消息、我的四个真实原生 tab 页面，不使用单组件视图切换模拟导航。
- [x] “我的”页面实现 MP-17 的演示身份区域，明确标注演示顾客切换不是微信真实登录。
- [x] 提供三个快捷顾客身份，分别预留正常预约、已有未来预约、取消或爽约历史的故事语义。
- [x] 切换身份时由服务端签发短期 Bearer 会话，后续接口不能接受客户端自行声明的顾客 ID 或角色。
- [x] 顾客只能读取自己的基础资料；篡改身份参数不能读取其他顾客数据。
- [x] 会话失效时小程序给出重新选择演示顾客的明确入口，并保留可恢复导航上下文。
- [x] 四个 tab 页面可通过真实页面路径直接打开，刷新或重新编译后恢复当前身份与选中导航。
- [x] 演示模式标记持续可识别但不压过主要内容，并符合小程序设计稿视觉基线。
- [x] 类型检查和接口测试覆盖身份切换、会话过期、越权读取与非法顾客标识。
