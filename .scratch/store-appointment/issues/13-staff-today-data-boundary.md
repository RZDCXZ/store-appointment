# 13 — 员工今日工作与履约资料边界

**What to build:** 让员工在手机或桌面快速看清本人今日工作，并只取得完成当前预约所需的顾客与宠物资料。

**Blocked by:** 02 — 后台演示账号与角色路由; 05 — 宠物档案与隐私同意; 08 — 提交并确认预约.

**Status:** ready-for-agent

- [ ] ST-02 我的今日预约、ST-03 本人预约详情、ST-08 完整手机号揭示均有可直接访问和刷新恢复的后台路由语义。
- [ ] 390px 首屏优先展示当前身份、班次、下一位宠物、迟到待处理、待核销和待完成队列。
- [ ] 员工只能查询分配给自己的预约；访问其他员工预约时服务端返回无权限而非空数据。
- [ ] 详情按履约顺序显示状态与时间、宠物资料、护理标签、护理注意事项、脱敏顾客信息、本次服务和宠物历史门店服务记录。
- [ ] 员工不能看到顾客其他宠物、无关预约、经营信息或店长管理操作。
- [ ] 完整手机号必须经过明确确认后揭示，并写入包含员工、顾客、预约和时间的追加式审计事实。
- [ ] 建立后续敏感操作可复用的不可覆盖审计写入接缝；前端不能直接写审计内容。
- [ ] 今日队列按行动紧迫度排序，预约状态标签和行动提醒使用不同视觉语义。
- [ ] 页面覆盖首次加载、无今日预约、局部错误、无权限和会话过期，桌面与 390px 均无阻断布局问题。
- [ ] API 与 Playwright 测试覆盖本人／他人预约边界、手机号揭示审计和移动端关键操作。
