# 09 — 店长工作台即时看到预约

**What to build:** 让店长在顾客创建预约后，通过风险优先的今日工作台和按员工日历看到同一笔预约与当前门店容量。

**Blocked by:** 02 — 后台演示账号与角色路由; 08 — 提交并确认预约.

**Status:** ready-for-human

- [x] MG-01 今日工作台和 MG-02 按员工日历分别使用独立后台路由，可直接访问和刷新恢复。
- [x] 工作台先展示演示时间、风险任务区域、今日状态摘要和按员工时间线，不把经营图表放在首屏。
- [x] 日历按四名员工分列，并区分非班次、休息、预约、十五分钟周转和当前状态。
- [x] 顾客创建预约后，API 发出 SSE 刷新提示；后台收到后重新获取事实而不是把 SSE 负载当作最终数据。
- [x] SSE 断开能自动重连，重连后重新拉取当前工作台和日历数据。
- [x] 点击预约块可进入可刷新恢复的预约详情入口；不存在仅靠组件内抽屉状态才能找到预约的情况。
- [x] 员工不能访问店长工作台、完整员工日历或跨员工预约查询。
- [x] 工作台和日历覆盖首次加载、局部更新、保留旧数据的可重试错误、无风险空态和无权限状态。
- [x] Playwright 验证创建预约后后台刷新、日历事实、角色边界和直接路由刷新。
- [x] 路由映射记录 MG-01、MG-02 及预约详情入口。
