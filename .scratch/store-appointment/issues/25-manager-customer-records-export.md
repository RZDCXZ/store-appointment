# 25 — 店长顾客与宠物档案及导出

**What to build:** 让店长集中查看顾客、宠物和历史门店服务记录，并按授权范围导出结构化经营资料。

**Blocked by:** 15 — 完成服务、服务终止与追加说明; 16 — 店长预约列表与代客预约.

**Status:** ready-for-agent

- [ ] MG-14 顾客与宠物档案使用独立后台路由，顾客列表、顾客详情和宠物详情均可直接访问和刷新恢复。
- [ ] 店长可按姓名、脱敏手机号和宠物搜索顾客，并查看本人资料、宠物、预约历史与门店服务记录。
- [ ] 宠物详情区分顾客护理注意事项和内部门店服务记录，不把两者合并成通用备注。
- [ ] 追加更正说明保留原记录、作者与时间，并在顾客档案中按时间顺序显示。
- [ ] 店长可按当前预约筛选条件导出 CSV，字段使用领域语言且不暴露数据库内部列。
- [ ] 店长可导出顾客与宠物层级 JSON，内容与当前授权范围一致。
- [ ] 每次导出写入包含操作者、筛选条件、导出类型和时间的审计事实。
- [ ] 员工不能访问门店顾客列表、跨顾客导出或其他员工无关的服务记录。
- [ ] 页面覆盖空结果、局部错误、敏感字段、无权限和大于一页数据的可用展示。
- [ ] API 与 UI 测试覆盖搜索、历史关联、CSV／JSON 结构、导出审计和越权。
