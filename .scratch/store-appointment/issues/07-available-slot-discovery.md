# 07 — 顾客查询真实可约时段

**What to build:** 让顾客按宠物、主要服务、增项和员工偏好逐步获得真实可预约的日期与时段，而不是浏览静态时间表。

**Blocked by:** 04 — 门店首页与服务目录; 05 — 宠物档案与隐私同意; 06 — 已发布排班形成可预约容量.

**Status:** ready-for-human

- [x] MP-06 选择宠物、MP-07 服务与增项、MP-08 员工偏好、MP-09 日期与时段分别落到独立小程序页面。
- [x] 预约草稿跨页面和刷新保持；缺失前置选择时直接访问后续页面会给出明确恢复路径，而非渲染错误状态。
- [x] 服务与增项实时计算价格、服务时长和完整技能要求，并始终由同一员工连续完成。
- [x] 可约时段使用上海本地十四个自然日、当前时间加两小时向上取整、三十分钟候选点和左闭右开区间。
- [x] 服务与十五分钟周转必须完整落在营业、已发布班次和可用区间内，不得跨越休息、停班或闭店。
- [x] 指定员工只返回该员工时段；“最快可约”按最早时间、当天已占用服务分钟数和固定员工编号确定结果。
- [x] 日期无时段时区分周一闭店、暂无合格员工、已约满和超出开放窗口。
- [x] 同一宠物已有重叠服务时不返回冲突时段，不同宠物仍可由不同员工同时服务。
- [x] 领域测试覆盖体型、技能、周转、时间取整、十四日边界、区间相邻和最快可约平局。
- [x] 路由映射记录 MP-06 至 MP-09，并验证每一步直接访问、前进、后退和刷新恢复。
