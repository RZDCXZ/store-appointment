# 27 — 经营看板

**What to build:** 让店长用明确公式理解服务工时、已完成服务标价、异常结果和顾客复访，而不把没有支付闭环的数据称为营收。

**Blocked by:** 15 — 完成服务、服务终止与追加说明; 23 — 逐笔处理受影响预约; 25 — 店长顾客与宠物档案及导出.

**Status:** ready-for-agent

- [ ] MG-17 经营看板使用独立后台路由，可直接访问、刷新和恢复所选周期。
- [ ] 默认显示最近三十天，并可切换七、三十、九十天，与前一个等长周期比较。
- [ ] 服务工时利用率严格使用已完成预约计划服务分钟数除以排班扣除休息和生效停班后的分钟数，不含周转、取消、爽约或终止。
- [ ] 已完成服务标价按预约价格快照汇总，并在数值旁持续显示“非实收金额”。
- [ ] 取消率按全部预约、爽约率按未取消预约计算，服务终止单独显示数量和比例。
- [ ] 九十天复访顾客占比只计算至少完成两次服务的顾客，并明确分母定义。
- [ ] 所有指标提供精确数值、公式和趋势文字，状态与趋势不只靠红绿颜色表达。
- [ ] 时间周期以预约最终计划开始日和上海业务日期归属，日期边界有确定测试。
- [ ] 员工不能访问经营看板或指标 API。
- [ ] 领域公式测试、API 测试和 UI 测试在固定数据下得到唯一结果，并覆盖空周期与局部查询失败。
