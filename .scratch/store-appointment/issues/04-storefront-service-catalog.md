# 04 — 门店首页与服务目录

**What to build:** 让顾客通过小程序理解茸光门店、三项主要服务、三项增项以及犬猫不同体型对应的确定价格和服务时长。

**Blocked by:** 03 — 小程序演示顾客会话.

**Status:** ready-for-agent

- [x] API 返回门店品牌、上海营业语境、三个主要服务、三个增项及完整服务规格，金额以人民币分表示。
- [x] 体型边界严格为小型不超过 10kg、中型超过 10kg 且不超过 25kg、大型超过 25kg，并有边界测试。
- [x] MP-01 首页和 MP-02 服务列表／详情落到独立小程序页面，可直接访问和刷新恢复。
- [x] 首页展示营业状态、主要预约入口、最近预约占位状态、主要服务和门店承诺；闭店时仍允许浏览未来日期。
- [x] 服务详情清楚展示适用犬猫、体型、确定价格、服务时长和可选增项，不出现支付或“起步价到店再议”的语义。
- [x] 页面使用已选视觉基线与仓库品牌素材，服务内容不依赖临时占位矩形或范围外能力。
- [x] 加载、无服务、局部查询失败和重试状态保持页面结构，查询失败不伪装为空数据。
- [x] 服务 API 和小程序逻辑测试覆盖规格选择、金额格式与错误映射。
- [x] 路由映射记录 MP-01、MP-02，并验证从首页进入详情以及直接打开详情。
