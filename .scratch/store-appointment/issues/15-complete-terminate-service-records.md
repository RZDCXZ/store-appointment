# 15 — 完成服务、服务终止与追加说明

**What to build:** 让员工在宠物到店后记录正常完成或异常终止，并形成不可被覆盖的门店服务记录。

**Blocked by:** 14 — 到店核销、迟到与爽约.

**Status:** ready-for-agent

- [ ] ST-06 完成服务、ST-07 服务终止、ST-09 追加更正说明具备独立可恢复的路由语义。
- [ ] 只有已到店且当前时间不早于计划开始的预约可以完成；不强制等待预计结束时间。
- [ ] 完成时自动生成包含宠物、主要服务、增项、员工和实际时间的结构化门店服务记录。
- [ ] 护理标签和内部文字为选填，不强迫员工填写空洞备注。
- [ ] 到店后无法继续履约时可进入已终止，原因必填，且不能伪装为已完成、已取消或爽约。
- [ ] 提前完成或服务终止后，实际结束加十五分钟周转，随后释放原计划剩余容量；原计划仍保留。
- [ ] 服务记录和原说明只读；员工可追加说明，店长可追加更正说明，均保留作者与时间。
- [ ] 顾客预约详情只显示实际完成时间，不读取门店服务记录或更正说明。
- [ ] API 状态机测试覆盖过早完成、未核销完成、核销后取消、重复完成、终止和容量释放。
- [ ] Playwright 覆盖移动员工完成、终止、追加说明以及状态刚变化后的重新拉取。
