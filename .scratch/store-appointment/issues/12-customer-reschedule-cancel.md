# 12 — 顾客取消与顾客改期

**What to build:** 让顾客在允许截止时间内自行取消或原子改期，并在截止后得到联系门店的明确下一步。

**Blocked by:** 10 — 并发争抢与相近建议; 11 — 顾客预约记录、详情、核销码与消息.

**Status:** ready-for-human

- [x] MP-15 改期与取消使用可直接访问的独立页面路径，并从预约 ID 恢复原安排和允许操作。
- [x] 当前时间早于或恰好等于开始前十二小时允许顾客取消或改期；少于十二小时由服务端拒绝并提示联系门店。
- [x] 顾客取消立即进入已取消终态、释放尚未发生的实际占用、作废核销码并生成通知与追加历史。
- [x] 顾客改期复用真实可约时段，原安排持续有效直到新员工与新时段在同一事务中占用成功。
- [x] 改期成功保留同一预约身份，保存原员工、原时间、操作者和新安排，并轮换核销码。
- [x] 改期发生并发冲突时保留原安排和顾客选择，返回相近建议，不产生半完成历史或重复通知。
- [x] 顾客不能通过该流程更换宠物或完全不同的主要服务；界面引导取消后新建。
- [x] 取消与改期命令要求幂等键，重复请求返回首次结果。
- [x] API 测试覆盖十二小时两侧边界、原子失败、码轮换、容量释放、越权和非法终态操作。
- [x] 路由映射记录 MP-15，并验证刷新、后退和冲突恢复。
