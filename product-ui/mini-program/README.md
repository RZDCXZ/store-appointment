# 茸光宠物洗护小程序设计稿

这是基于 `DESIGN_PRD.md` 实现的高保真、可交互移动端设计稿。设计基线来自 `design-reference/mp-01-option-1.png`。

## 页面范围

完整覆盖 MP-01 至 MP-18：

- 首页、服务项目、宠物列表、新建/编辑宠物与隐私同意。
- 预约五步流程：宠物、服务与增项、员工偏好、日期与时段、确认。
- 预约成功、时段冲突与相近建议。
- 预约记录、预约详情与核销码、改期与取消。
- 模拟消息、我的、数据导出与资料删除。

## 可交互黄金路径

1. 首页 → 为宠物预约洗护 → 确认预约 → 预约成功。
2. 日期与时段 → 选择 `16:30` → 时段冲突 → 相近建议。
3. 首页 → 查看详情 → 改期或取消预约。
4. 底部导航 → 我的 → 宠物档案 / 隐私同意 / 数据与隐私。

设计稿保留 iPhone 与 Pixel 10 设备预览，可用右上角设备选择器切换。
