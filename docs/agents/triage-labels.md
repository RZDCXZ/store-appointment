# Triage 标签

工程技能使用五种标准 Triage 角色。下表将这些角色映射到本仓库 Issue Tracker 使用的实际标签字符串。

| mattpocock/skills 中的标签 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估该 Issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可交给异步 Agent 实现 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提到某种角色时，应使用表中对应的标签字符串。

如果本仓库以后采用不同的标签词汇，可直接修改右侧“本仓库标签”列。
