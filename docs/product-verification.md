- 管理端：`product-ui/admin/design-reference/mg-01-option-1.png`

本轮在 Chrome 151 中逐页抽查登录、店长工作台、预约日历、受影响预约、通知重试、演示重置，以及 390px 员工今日工作、预约详情和核销页。茸光的暖米白画布、深鼠尾草主操作、克制珊瑚风险色、领域词汇和状态语义在三端保持一致；小程序保留面向顾客的低密度卡片，后台保留任务型高密度信息。

发现并修复的阻断偏差：员工核销码输入框的字距触发 CSS Grid 最小内容宽度，导致 390px 横向滚动。修复后由 Playwright 对该真实路由持续断言 `scrollWidth <= innerWidth`。

后台验收覆盖可见焦点、键盘入口、非颜色状态文字、表单标签与关联错误、危险操作确认及弹层焦点返回。移动页面的主要操作目标遵守设计基线的最小 44px 触控尺寸。加载、空数据、保留旧数据的可重试错误、无权限、认证过期、字段错误、冲突和幂等重试由代表性页面组件复用，并由页面测试覆盖。

## OpenAPI、架构、素材与边界

- 本地 API 启动后在 `/docs` 提供按领域分组的 OpenAPI 页面；每个控制器操作均有中文摘要。它描述的是本地 HTTP 契约，领域类型的单一事实仍在 `packages/contracts`。
- 架构决策见 `docs/adr/0001` 至 `0010`：本地作品集边界、三端拆分、单宠物单员工预约、不可覆盖历史、匿名化、显式生命周期、容量变更、原生小程序、PostgreSQL 排除约束和事务 outbox／幂等命令。
- 茸光宠物、员工和品牌照片是产品原型阶段生成并随仓库保存的栅格素材；小程序运行时使用压缩 JPG。原型的手机边框、系统状态与键盘素材只用于 `product-ui` 设计演示，不随正式小程序发布。对外发布前仍应单独复核所有生成素材和模板素材的使用许可。
- 本地演示不提供真实微信登录、订阅消息、短信、支付、地图、对象存储、第三方日历、云部署、备份恢复或生产监控。通知、身份切换、时钟推进和数据重置均明确标为模拟能力；宠物上传仅写入被 Git 忽略的本地目录。
