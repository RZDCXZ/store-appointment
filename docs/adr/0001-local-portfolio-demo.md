# 以本地可验证的作品集案例为交付目标

本项目选择实现一个公开源码、可在本地完整运行的宠物洗护预约案例，用于向单门店经营者和外包合作方证明产品与工程能力，而不按正式上线产品建设。核心业务规则、权限和异常流程必须可验证；微信认证、支付、消息及生产运维等第三方边界使用明确标注的模拟实现，因为真实接入会引入与作品集证明目标无关的资质、费用、合规和维护成本。首版只定义真实微信登录与订阅消息的适配器边界并记录接入条件，不实现无法纳入本地验收的半成品适配器。项目保持清晰边界，但不预先建设跨行业配置、多租户或通用 SaaS 能力。演示数据通过重置脚本确定性生成，并支持以 `DEMO_NOW` 固定上海业务时间；启用时界面必须明确标识演示时间，保证录屏和自动化验证不会因数据过期而失效。本地运行承诺为两步：`pnpm demo:up` 启动 PostgreSQL、API 和后台，随后使用微信开发者工具导入小程序并填写使用者自己的测试 AppID；AppSecret 不进入仓库或客户端。
