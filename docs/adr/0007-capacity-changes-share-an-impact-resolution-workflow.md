# 容量变更共用受影响预约处理流程

只有未来十四天的已发布排班形成顾客可预约容量；每周排班模板只生成草稿。修改营业时间、已发布班次或休息，创建员工停班或门店临时闭店时，一旦涉及已有预约，变更先进入待处理状态并立即阻止该区间的新预约，再由店长逐笔换员工、改期或取消受影响预约，全部处理后才生效。系统不能自动取消或移动顾客预约，也不允许店长通过强制重叠绕过容量约束。

影响快照中的预约可能在待处理期间经其他有效入口改期、取消或进入履约终态。若当前预约已经不再占用目标容量，店长必须执行“影响处理确认”，把现有预约历史与该容量变化显式关联后才能推进进度；该确认不是第四种预约变更，不得再次移动、取消或覆盖预约事实。若预约已到店且仍占用目标容量，则容量变化保持待处理，必须先完成或终止服务，再确认形成的终态。创建容量变化时若预约已经到店，应直接拒绝创建。
